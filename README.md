# 清華拾光 · 校門與大草坪修訂版（v7）

Python / pygame-ce 校園探索遊戲，原生 1280×720、非像素 2D 手繪風格。本版補入大草坪、北校門廣場、教育館及綜四周邊步道，並將目前地圖中的建築全部換為各自的照片參考重繪立面。

## 開啟遊戲

桌面「清大」內開啟 **清華拾光-校門大草坪修訂版-v7.exe**。標題選「前往校門與大草坪」查看本次修改；按 M 選教育館或綜合四館，靠近入口按 E 進入。按 C 可分頁查看 34 處建築的外觀與觀察說明。

GitHub 原始碼不包含 EXE、完整專案 ZIP 或預覽圖。下載原始碼後，可依下方方式執行或自行打包。

## 操作

| 功能 | 操作 |
|---|---|
| 移動 / 跑步 | WASD、方向鍵 / Shift |
| 交談、進入建築、室內設施、景點觀察 | E 或 Enter |
| 校園地圖與目的地移動 | M，點建築或右側目的地；上一頁／下一頁切換列表 |
| 地圖細看道路 | 滾輪或 + / -；按住右鍵拖曳；「全校總覽」恢復 |
| 任務與觀察手札 | Q |
| 校園建築觀察 | C，點建築頁籤及上一頁／下一頁 |
| 選擇下方功能 / 使用 | 1–6 / Space；也可點按鈕 |
| 單車 | B |
| 暫停 / 離開室內 | Esc |
| 全螢幕 | F11 |

下方功能列為地圖、手札、相機、飲水、餐點與單車。補給來自小吃部、補水點及初始補給。遊戲沒有地上物品撿取、隱藏道具、素材採集或製作流程。

## 本版內容

- 160×224 格地圖、12 個區域、34 處可進入建築、15 位 NPC、8 條走訪及訪談任務。
- 北校門改為冊字立柱與開放廣場；補入大草坪、旗台、環道、三角鐘辨識點及教育館、旺宏館、行政大樓和綜四的連接步道。
- 新增綜四／郵局、化工館、醫輔大樓、綜三、舊育成中心、動機化學實驗館、材料科技館、材料實驗館及合金實驗館。綜四與舊稱研發大樓合併表示；資電館／劉炯朗館的重複目的地也合併。
- 29 處非宿舍建築使用各自的照片參考重繪外觀（28 張立面圖塊及 1 個 Python 專用立面），五棟宿舍沿用專用立面；移除通用方塊立面繪製。
- 教育館新增課程討論區，綜四新增郵務公告；按 E 閱讀可記錄觀察。
- 建築觀察擴充為 7 頁；地圖目的地可分頁選擇。中英文長文字會換行或調整按鈕字級。
- 保留 v6 的新齋、成功湖島嶼與橋、主要道路、單車、相機、角色自訂、飢餓口渴、雙語、自動存檔及三個手動槽。

目前未收錄清大全部館舍和支路。建築占地、外觀展開、樓翼及步行距離使用遊戲尺度；不能作為導航或測繪資料。室內仍為共用示意空間及個別互動點，五棟宿舍共用依仁齋四人房重繪的配置。完整參考及限制見 [地圖修訂說明](MAP_REFERENCE.md)。

## 執行與測試

使用 Python 3.14：

```powershell
git clone https://github.com/nthukenlee/project.git
cd project
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

```powershell
python -m unittest discover -s tests -v
python main.py --smoke-test outputs/smoke/report.json
```

21 項測試涵蓋道路／步道／橋／入口碰撞、雙向角色移動、NPC 與入口可達、宿舍與教育館／綜四互動、景點觀察、目的地分頁、立面覆蓋、雙語、任務、存檔與 Windows 暫時檔案鎖定。

```powershell
python -m pip install -r requirements-dev.txt
.\build_windows.ps1
```

打包輸出為 `outputs/NTHUWalk2D.exe`。交付版中文檔名如上。`--smoke-test` 使用 SDL dummy driver 輸出 64 張繁中／英文場景圖及 JSON 報告，涵蓋新增場景、兩館室內、7 頁建築導覽、詳細地圖與既有湖泊宿舍。這項檢查不等同在未安裝 Python 的另一台電腦上人工驗收。

## 存檔、版本與來源

沿用 `%LOCALAPPDATA%\NTHUPixelAdventure`。v7 存檔版本為 4。舊版存檔保留角色、任務、照片與觀察；首次載入回到北校門，避免舊座標落在調整後的建築中，不會刪除原存檔。

Git 記錄原始碼、資料、素材與文件；排除 EXE、ZIP、建置檔、暫存及玩家存檔。美術及資料來源見 [ATTRIBUTIONS.md](ATTRIBUTIONS.md)、[v5 美術規格](assets/ART_DIRECTION_V5.md)、[v6 新齋素材](assets/ART_DIRECTION_V6.md) 和 [v7 建築素材與提示詞規格](assets/ART_DIRECTION_V7.md)。

這是非官方作品。目前以校園走訪、訪談及室內閱讀為主要玩法，原訂 60–90 分鐘內容與全部實景還原尚未完成驗收。
